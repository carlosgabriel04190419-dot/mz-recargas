menu_book Cómo conectarlo
  1. Consigue de tu proveedor la dirección de su API (URL) y tu llave (API key). El acceso suele ser por tiempo limitado (por ejemplo 15 días): al probar la conexión verás aquí cuándo vence. Renovarlo no cambia la llave, así que no tienes que tocar nada más.
  2. Guarda la llave solo en Supabase: en Edge Functions → Secrets crea PROVEEDOR_URL (la dirección) y PROVEEDOR_API_KEY (la llave). Nunca la pegues en esta web, en el código ni en un chat.
  3. Si quieres ensayar antes, crea el secret PROVEEDOR_MODO con el valor simulado y pulsa Probar conexión. Según en qué termine el ID: 000 el jugador "no existe"; 111 el proveedor "está caído"; 999 la recarga "se rechaza"; 888 "no responde"; 777 queda "en proceso" y a los 20 segundos se entrega; 666 queda "en proceso" y luego se rechaza; 555 se queda "en proceso". Cualquier otro ID funciona. En este modo no se entrega nada de verdad.
  4. Pon PROVEEDOR_MODO en real y pulsa Probar conexión: debe decir Conectada y mostrar tu saldo, cuándo vence la API y cuántas consultas de nickname te quedan. Esa prueba solo consulta datos; no compra nada.
  5. Carga saldo en el proveedor (se paga en USDT): cada recarga automática se descuenta de ahí. Sin saldo, las entregas fallan. El saldo de arriba se pone al día solo con cada compra y cada vez que abres este panel (o pulsas Actualizar).
  6. Pulsa Ver catálogo del proveedor y luego Asignar los que coinciden por nombre: los paquetes que se llaman exactamente igual en tu tienda y en el proveedor (por ejemplo los diamantes de Free Fire) reciben su código solos. Para el resto, copia el código a mano en Paquetes → Editar → Código en el proveedor. Lo que el proveedor no vende por API (promo de primera recarga, cajas, fragmentos, Pase Booyah) se sigue entregando a mano.
  7. Activa Entregar los pedidos automáticamente y haz una compra pequeña con tu propio ID antes de abrirlo a todos.
  8. El nickname solo existe para Free Fire. Cada consulta nueva gasta una del cupo de la API (se reinicia al renovar) y los IDs ya consultados se recuerdan 24 horas. Si el cupo se acaba o el validador falla, la compra sigue normal, solo que sin nickname.
  9. Si el proveedor tarda en confirmar una recarga, el pedido queda en El proveedor la está aplicando y se resuelve solo: se consulta su estado cuando abres Pedidos y cuando el cliente abre Mis pedidos. También puedes pulsar Consultar estado. Mientras está así no se puede cancelar ni marcar a mano (así no se entrega dos veces).
  10. Si el proveedor rechaza la llave (venció el acceso, la pausaron o generaron otra), la conexión se apaga sola: las compras nuevas vuelven a entrega manual hasta que lo resuelvas y pulses Probar conexión.
